Acknowledgements

Inspect uses a small set of open source packages in the current rewritten app.

swift-certificates

Apple's X.509 package used for certificate parsing and related models.

github.com/apple/swift-certificates

swift-asn1

Apple's ASN.1 package used by the certificate parsing layer.

github.com/apple/swift-asn1

swift-crypto

Apple's crypto package used in tests and certificate-related tooling.

github.com/apple/swift-crypto

tun2proxy

Rust-based TUN interface proxy used by the Live Monitor packet tunnel for traffic forwarding and passive TLS observation.

github.com/tun2proxy/tun2proxy
